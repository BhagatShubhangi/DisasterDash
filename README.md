# 🌐 DisasterDash - AI-Based Disaster Management System

_DisasterDash_ is a fully responsive, AI-enhanced web platform designed to predict, respond to, and provide resources during natural disasters. With interactive maps, real-time weather updates, emergency information, and AI predictions, it helps users prepare for and respond effectively to crises.


## 🚀 Features

- 🌍 **Interactive Map** (via Leaflet.js) to visualize disaster-prone areas
- 📈 **AI-Based Predictions**: Simulated prediction and response data
- 🧰 **Emergency Resources** like contacts, shelters, and evacuation routes
- 🌤️ **Live Weather Widget**
- 🌙 **Dark Mode Toggle**
- 📊 **Historical Disaster Data Visualization** using Chart.js
- 🎨 **Smooth Animations** using AOS and custom CSS keyframes

---

## 🛠 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Libraries & APIs**:
  - [Leaflet.js](https://leafletjs.com/) – Interactive Maps
  - [Chart.js](https://www.chartjs.org/) – Graph Visualization
  - [AOS](https://michalsnik.github.io/aos/) – Scroll Animations
  - Font Awesome Icons

---




## 📌 How to Run

1. Clone the repository or download the files
2. Open `index.html` in your browser
3. Ensure internet access for CDN-linked resources (Leaflet, AOS, Font Awesome, etc.)
